# 🎯 Гайд: Как Категоризировать и Назвать Файл

Используйте этот алгоритм (промпт) при добавлении любой новой заметки в репозиторий `holiday-code`.

## Шаг 1: Определите Язык и Основную Область

Прежде всего, определите, к какому из трех языков относится код, а затем – какова его **основная функция** или **концепция**.

| **Язык** | **Если Код в основном про...** | **Выберите Папку** |
| --- | --- | --- |
| 🐍 **Python** | **Короткий, хитрый способ** что-то сделать (List Comprehension, Walrus). | `idioms/` |
|  | **Управление потоком** (async, await, aiohttp). | `async_await/` |
|  | Использование **продвинутых встроенных классов** (`dataclasses`, `deque`). | `data_structures/` |
|  | **Структурный паттерн** (Фабрика, Цепочка ответственности). | `patterns/` |
| 🐹 **Golang** | **Параллельная работа**, goroutines, channels, `select`. | `concurrency/` |
|  | **Правильное объявление интерфейсов**, встраивание (embedding), DI. | `patterns/` |
|  | **Использование `errors.Is`/`As`**, или `panic`/`recover`. | `error_handling/` |
|  | Обобщенные функции для слайсов, контейнеров (Go 1.18+). | `generics/` |
| 🟦 **TypeScript** | **Сложные типы**, Mapped Types, Conditional Types, `infer`. | `advanced_types/` |
|  | **Встроенные утилиты** (`Omit`, `Pick`, `Required`). | `utility_types/` |
|  | **Декораторы** (`@Component`, `@Injectable`). | `decorators/` |
|  | ООП-паттерны (Классы, Абстракции, Интерфейсы). | `oop_interfaces/` |

## Шаг 2: Придумайте Описательное Имя Файла

Имя файла должно быть кратким, но содержательным. Оно должно объяснять, *что* делает код, а не просто *какие данные* он обрабатывает.

### 📝 Правила Именования:

1. **Формат:** Используйте только нижний регистр и подчеркивание (`snake_case`).
2. **Фокус на Концепции:** Имя должно отражать **паттерн** или **используемую конструкцию**, а не конкретную задачу.
3. **Краткость:** Не делайте имя слишком длинным.

| **❌ Плохое Имя (Слишком конкретно)** | **✅ Хорошее Имя (Фокус на Паттерне)** | **Причина** |
| --- | --- | --- |
| `check_user_input.py` | `chain_of_responsibility.py` | Фокус на паттерне, а не на данных. |
| `copy_map.ts` | `deep_readonly_type.ts` | Фокус на продвинутом типе, а не на действии. |
| `add_numbers_sync.go` | `fan_out_pattern.go` | Фокус на архитектуре конкурентности. |
| `get_list_items.py` | `custom_iterator.py` | Фокус на том, как итерирование реализовано. |

### 💡 Итоговый Путь:

После всех шагов вы получите полный путь к вашему файлу:

```
/<язык>/<концепция>/<имя_файла>.<расширение>

```

**Пример:** `python/patterns/chain_of_responsibility.py`
